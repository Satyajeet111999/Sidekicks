# Email Automation Dashboard

This project is a Streamlit-based UI to automate email workflows for employee travel requests. It has three dashboards:

- **Employee Dashboard**: For submitting travel requests.
- **Manager Dashboard**: For approving or rejecting employee requests.
- **Admin Dashboard**: For booking travel based on approved requests.

## How to Run

1. Clone or unzip the project folder.
2. Navigate to the folder in terminal.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```

Ensure you have Python 3.8+ and `streamlit` installed.
